# **App Name**: ApexTracker

## Core Features:

- Real-Time Price Monitoring: Display live price updates for selected fiat and crypto pairs.
- Customizable Watchlist: Allow users to add and remove currencies/cryptocurrencies from their watchlist.
- Interactive Historical Charts: Provide interactive charts showing historical price data for selected currencies/cryptocurrencies.
- Configurable Price Change Alerts: Enable users to set up alerts that trigger when a currency/cryptocurrency's price changes by a specified percentage.

## Style Guidelines:

- Dark color scheme to reduce eye strain and improve focus.
- Primary color: Electric Green (#7CFC00) to indicate gains and positive trends.
- Accent color: Crimson Red (#DC143C) to indicate losses and negative trends.
- Background color: Dark grey (#282828) for high contrast and readability.
- Body and headline font: 'Inter', a sans-serif font, will be used to give a clean, machined look.
- Simple, minimalist icons for currency symbols and interface elements.
- Dashboard layout with clear sections for watchlist, charts, and alerts.
- Smooth transitions and updates for real-time data display.
